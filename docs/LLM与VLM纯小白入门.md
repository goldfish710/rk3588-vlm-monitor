# LLM 与 VLM 纯小白入门

> 零基础版:不需要任何机器学习背景,只要求你会用电脑、写过点程序。
> 全文不用公式,只用比喻。看完你会明白:聊天机器人为什么会说话、
> 为什么会"一本正经地胡说八道"、以及怎么用好它。

---

## 第 1 章:先感受一遍完整旅程

你在 DeepSeek 输入"你好",它回"你好呀,有什么可以帮你?"。这一瞬间发生了什么?

```
你的输入"你好"
  → 切成小块数字(比如 [57668, 105])
  → 每块数字查表变成一串"含义向量"
  → 经过几百层"信息加工流水线"
  → 吐出下一个最可能的数字
  → 把数字变回汉字,显示给你
```

它没有"理解"你,它做的是:**根据你写的字,猜下一个字该是什么,然后把这个字接上去,再猜下一个,一直猜到应该结束为止**。

就像手机上输入法的"下一个词联想",只不过这个联想能力来自读完了半个互联网。

一句话总结:**大语言模型 = 一个超级强大的"下一个字猜测器"。**

---

## 第 2 章:电脑是怎么"读"文字的

电脑只懂数字。所以第一步是把文字切成数字:

- 把"你好"切成小块:**token**(词元)。可能切成"你""好",也可能整词"你好"成一个块
- 维护一张大表(词表),每块对应一个编号。比如"你"=57668
- 你输入的任何文字都变成一串编号,这就是"**token 化**"

为什么同一个词有时切法不同?词表只装**最常用的几万个块**,生僻词会被拆成更小的碎片(像查字典:常用字单独成词条,生僻字拆笔画)。这套切分算法叫 **BPE**——你不用知道它怎么算,知道"文字 → 编号"这一步叫 token 化就够了。

实用知识:中文比英文"费 token"。同样一句话,中文往往切成更多块。用 API 是按 token 计费的,所以中文对话比英文略贵——这是正常的,不是你被坑了。

## 第 3 章:什么是"模型"和"训练"

### 3.1 模型 = 一个装满旋钮的机器

想象一个巨大的机器,里面有**几千亿个可调节的旋钮**(参数)。你从一端倒入文字编号,机器内部经过层层加工,从另一端输出"下一个字的预测"。

旋钮拧在不同位置,机器就表现出不同的行为——就像收音机调台。**"训练"就是把这几千亿个旋钮拧到正确位置的过程**。

### 3.2 训练 = 小学语文填空题

最核心的训练方法是"完形填空":

```
把网上的一段话挖掉最后一个词:
"今天天气真____"
让模型猜。它猜"好",对了(原文就是"好"),把旋钮往"更容易猜对"的方向拧一点点。
错了,就往反方向拧。
```

用互联网上的**全部文本**把这道题做几万亿遍,机器就逐渐掌握了语言规律:语法、常识、甚至逻辑。这个过程叫**预训练**,做出来的模型叫**基座模型**。

注意:这个过程**不需要人来标注答案**——原文里挖掉的词就是标准答案。这是大模型革命的关键:免费的自监督数据。

## 第 4 章:注意力机制——模型的核心招式

预训练拧的旋钮里,最重要的是一个叫"**注意力**"的机制。比喻:

> 你在读一段话:"小明把苹果给了小红,因为**她**饿了。"
> 你立刻知道"她"指小红——你的注意力自动跳到了"小红"上。

模型没有眼睛,它靠注意力机制做同样的事:计算句子中**每两个词之间应该互相看多重**。生成"她"后面内容时,模型会给"小红"分配高注意力,给"苹果"分配低注意力。

这就解释了为什么模型能:
- 理解指代关系("它"指什么)
- 长距离关联(第一段提到的线索,第十段还能用上)
- 按语义而非位置组织信息

实际工程中会用"多头注意力":多组并行的注意力,有的关注语法、有的关注指代、有的关注情感——像一支各司其职的编辑团队。

## 第 5 章:为什么"大"模型才聪明

| 模型规模 | 旋钮(参数)数量 | 能力 |
|---|---|---|
| 早期小模型 | 1~10 亿 | 语法还行,逻辑混乱 |
| GPT-3 | 1750 亿 | 忽然能写文章、翻译、做数学 |
| 现在的主流 | 几千亿~上万亿 | 推理、多步规划、用工具 |

经验规律:**规模越大、读的书越多,能力可预测地变强**(缩放定律)。有些能力小模型完全没有,大到一定程度"突然出现"——这叫**涌现**。

代价:训练一次要几千张显卡跑几个月,花几千万美元。所以全世界只有少数公司能做出基座大模型,多数人是"站在巨人肩膀上"用它们。

## 第 6 章:模型是怎么"学会好好说话"的(训练三段论)

读完整个互联网的模型只是"续写机器"——你问"1+1等于几?",它可能接着你的话往下编。要变成"助手",还要两步:

| 阶段 | 比喻 | 干什么 | 数据 |
|---|---|---|---|
| ① 预训练 | 通读天下书 | 学会语言和知识 | 互联网全部文本(不需要标注) |
| ② 监督微调(SFT) | 请家教 | 教"问题→回答"的格式 | 人工写的几万条问答对 |
| ③ 强化对齐(RLHF) | 学礼貌 | 教"什么该说、什么不该说、怎么说招人喜欢" | 人类对多个回答的**排序**(不是评分,只要排先后) |

第三步之后,模型会礼貌、会拒绝有害请求、会承认不知道——但也有人说它"变笨了一点"(被调教得过于保守),这有个专门的词叫"对齐税"。

面试/聊天谈资:你用的任何商用助手都经历了这三步;开源的"基座模型"一般只做完第一步或第二步。

## 第 7 章:它为什么会"一本正经地胡说八道"

因为它的训练目标是"**说得像人话**",而不是"**说得对**"。

"明朝灭亡于 1644 年"和"明朝灭亡于 1645 年",在模型眼里都是"流畅自然的回答"——如果它没学好,两个都可能给。专业术语叫**幻觉(hallucination)**。

实用应对:
- 重要事实让它"给出处"或"不确定就说不知道"
- 提供资料让它基于资料回答(这就是 RAG 的思想,见第 10 章)
- 心里有数:它是"文笔好、知识广、但偶尔吹牛"的助手

## 第 8 章:怎么和它对话(提示词与参数)

### 8.1 提示词(Prompt)

你写的话就是提示词。写好提示词的诀窍:**像给新来的实习生布置任务**:

```
❌ "写个总结"
✅ "你是我的项目助理。下面是我项目的开发日志,用三句话总结这个项目做了什么,每句不超过30字:……"
```

几个实用技巧:
- **给角色**:"你是……" 定下人设和语气
- **给要求**:格式、长度、受众、语气
- **给例子**(few-shot):先示范一个你想要的答案
- **让它一步步想**(思维链):"请一步一步分析"

### 8.2 三个常用参数(调过 API 的人都知道)

- **temperature(温度)**:回答的"随机性"。调 0:每次都答一样(严谨、无聊);调 1:活泼有创意(但也更容易胡说)。写代码/查事实调低,头脑风暴调高
- **max_tokens(最大长度)**:最多输出多少字块,防止它长篇大论
- **top_p**:和温度类似,另一种限制"离谱词"的方式,不用细究

## 第 9 章:VLM——给 AI 装上眼睛

LLM 只会"读",不会"看"。VLM(Vision-Language Model,视觉语言大模型)就是会看图的大模型。

核心难题:**文字和图像是两种完全不同的数据**。怎么把一张图"说"给只会读文字的模型听?

解法三步(像给盲人请了个翻译):

```
图片 → ① 视觉编码器:把图切成小块,每块变成向量
     → ② 对齐层(翻译官):把"图像语言"翻译成模型熟悉的"文字语言"
     → ③ 大语言模型:对着翻译过来的内容,正常回答
```

- ① 视觉编码器通常是 **ViT**:把图切成 16×16 的方格,每个方格当一个"词"处理——就是"图像版 token 化"
- ② 训练"翻译官"的经典方法是 **CLIP**:拿 4 亿组"图片+配文",训练"图与对的配文靠近、与错的配文远离"——对齐后两种语言就能互通
- ③ 后面的 LLM 基本不变,发挥它原有的推理能力

训练 VLM 也分三步:先图文预训练(看图配文)→ 问答微调(看图回答)→ 人类反馈对齐。

实用例子:把一张房间照片发给 VLM 问"房间里有哪些安全隐患?",它会数出"地上有电线、桌角尖锐……"——这是"理解+推理",不是简单的识别。

## 第 10 章:大模型世界的常用词扫盲

| 词 | 一句话解释 |
|---|---|
| **API** | 模型的"远程柜台",你发文字过去它回文字,按量计费 |
| **token 计费** | 按输入+输出的文字块数收费,中文比英文略贵 |
| **流式输出** | 一个字一个字往外蹦(像打字机),不等整段生成完 |
| **上下文窗口** | 模型一次能"记住"的对话长度,超了会忘记开头 |
| **RAG** | 把你的资料库接给模型:先检索相关内容,再让模型基于资料回答(治幻觉+私有知识) |
| **Agent(智能体)** | 让模型"会动手":它能调用搜索、写文件、查数据库,循环完成任务 |
| **工具调用** | Agent 的基础:模型输出结构化指令表示"我要用某某工具" |
| **开源 vs 闭源** | 开源=权重公开可自己部署(如 Llama、Qwen、DeepSeek 部分模型);闭源=只能调 API(GPT 系列等) |
| **MoE** | "专家团队"架构:模型由多个专家组成,每个问题只唤醒一部分专家——大而省算力(DeepSeek 的核心技术) |
| **推理模型** | 回答前先打一大段"草稿"(思考过程),数学/代码更强,但慢且贵 |
| **蒸馏** | 用大模型当老师,把能力"压缩"进小模型,让端侧也能跑 |
| **微调(Fine-tuning)** | 在别人训好的模型上,用你的少量数据继续训练(量体裁衣) |

## 第 11 章:零门槛动手路线(照着做就能入门)

**第一步(今天,10 分钟)**:打开 DeepSeek 网页版,把第 8 章的"好提示词"试一遍,感受温度参数(网页版设置里有)。

**第二步(这周,半小时)**:写一个 20 行 Python 脚本调用 DeepSeek API:

```python
import requests

resp = requests.post(
    "https://api.deepseek.com/chat/completions",
    headers={"Authorization": "Bearer 你的key"},
    json={
        "model": "deepseek-v4-flash",
        "stream": True,
        "messages": [
            {"role": "system", "content": "你是幽默的助手"},
            {"role": "user", "content": "用一句话介绍你自己"},
        ],
    },
    stream=True,
)
for line in resp.iter_lines():
    if line and line.startswith(b"data:"):
        print(line)   # 逐块打印,亲眼看到"流式输出"
```

**第三步(有空时)**:找一张照片,用通义千问 VL(免费额度)或 DeepSeek 的视觉模型让它描述图片——体验第 9 章。

## 第 12 章:常见误区(FAQ)

**Q:它会思考吗?**
不会。它是在做极复杂的"下一个字预测"。它表现出的"思考"是语言规律中隐含逻辑的副产品。推理模型让它先写草稿,只是把"思考"做成了看得见的形式。

**Q:它懂我在说什么吗?**
取决于"懂"的定义。它建立了非常精细的文字关联网络,能做出符合语义的响应;但它没有意识、没有真实体验,只是模式匹配到了极致。

**Q:它有记忆吗?**
单次对话内,你发过的所有内容都在它的"上下文"里(所以它记得你刚说过什么)。关掉对话,它全忘了。想让产品"记住"用户,要靠外部存储(数据库)+ RAG,不是模型本身。

**Q:它联网吗?**
默认不联网,知识截止于训练数据的时间点。让它"搜索"需要显式接搜索工具(Agent)。

**Q:大模型会取代程序员吗?**
它是效率工具:能写大部分样板代码,但需求澄清、架构判断、调试定位仍需人。会用它的人取代不会用的人,是更准确的描述。

**Q:我的普通电脑能跑大模型吗?**
小模型(10 亿~80 亿参数,量化后)可以在好点的消费级显卡/16GB 内存电脑上跑;千亿级模型必须云端。手机正在"能跑小模型"的边缘。

## 一页纸总纲(背下来就入门了)

1. LLM = 读完互联网的"下一个字预测器",本质是概率游戏,不是魔法
2. 文字先 token 化 → 向量 → 几百层注意力加工 → 预测下一个字
3. 训练三段:预训练(读书)→ SFT(家教)→ RLHF(学礼貌)
4. 会"幻觉"是因为训练目标像人话,不是绝对正确
5. 用好它靠提示词:给角色、给要求、给例子
6. VLM = 视觉编码器 + 对齐翻译 + LLM,给 AI 装眼睛
7. 产业格局:极少数公司训底座,全世界用 API;端侧小模型是趋势但还很弱
