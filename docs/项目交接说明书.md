## 一、项目定位（一句话）

**RK3588 板载 VLM 智能家居监护终端**：一台"能看懂画面"的板端 AIoT 设备——YOLO pose 跌倒候选 → 板载 Qwen3-VL-2B 看图复核分级报警 + 周期场景理解时间线 + 公网 MQTT 远程操控（快照/视觉问答），另有完整的音视频（双码流 RTSP、fMP4 录像）与全本地语音链路（zipformer ASR + Piper TTS + VLM 对话）。

**项目性质**：用户个人项目，用于**嵌入式 AI 岗位求职**——文档体系（简历/技术文档/面试讲稿）是重要产出，功能设计要"贴切工业产品、面试可讲"。

### C 阶段协议速查（未实测，接手者验收时看）

- Topic（`{device_id}` 加载时替换为 `[event] device_id`，板端当前=`rk3588_home_001`）：
  - 上行：`home/fall`（报警，retained）、`home/{id}/timeline`（摘要）、`home/{id}/resp`（命令应答）、`home/{id}/state`（online/offline retained）

## 五、关键设计决策（接手者必读，改代码前先理解）

1. **VLM 单线程红线**：VlmEngine 全部调用只发生在 chat_llm 线程；唯一例外 `cancelRun()`（rkllm_abort，官方跨线程打断 API，内部先 rkllm_is_running 判断）。巡检/远程命令都放在 chat_llm loop 里跑，不新建线程。
2. **跌倒静默报警**（用户拍板）：复核后本地不播语音——报警接收方是监护人；语音通道只服务老人主动发起的交互（唤醒对话/求救词）。ChatEngine::onFallEvent 已删除。
3. **优先级仲裁**：复核(1) > 语音(2) > 远程(3) > 巡检(4)。复核到达时：语音/巡检/远程生成中→`rkllm_abort`；vision 编码无法中断→编码后"让路检查点"跳过 LLM 段；播放中→句间丢句静默。复核完成后顺延下次巡检一个完整周期。
4. **证据先行**：跌倒候选的图/预录录像/DB 记录在 VLM 复核**之前**落盘；复核超时（默认 12s）按"未确认"直报（宁报勿漏），VLM 明确排除才发 cleared 低打扰通知（双保险）。
5. **三道报警闸门**（person_tracker，2026-09-10 照片场景反复踩坑后成型）：① 单人 alarm_armed（报警后需连续 ≈1s 非跌倒帧才重新武装）② **场景保险丝 scene_fall_pending_**（报警后挂起，连续 ≈2s 画面无确认跌倒者才解除——持续倒地画面永不重报）③ 15s 冷却。语义：同一次跌倒只报一次，起身后再跌倒算新事件。
6. **VLM 输入用干净帧**（用户拍板）：画框前的原始画面（无框/骨架/标签）——标注干扰大模型姿态判断。RTSP 直播画面仍带框（给人看）。绘图参数：线宽 6、点半径 6（显示阈值 0.10）、字号 22。
7. **漏检宽限期**：追踪目标漏检 15 帧（≈1s）内保留并继续匹配——防单帧漏检删人重加（曾致 ID 抖动+框闪烁）。
8. **显示姿态粘性**：跌倒显示态需连续 ≈1s 非跌倒才退出——防阈值边界抖动红蓝频闪。
9. **MQTT 回调线程只入队**；SQLite 读写都经 EventManager worker 串行化（单连接）；FrameProvider 只在被请求时做转换拷贝（平时零开销）。
10. **老 config.ini 兼容**：无 `[vlm_pipeline]` 节→代码默认值生效；`vlm_enable=0`→复核链整体旁路（回退旧行为+云端 DeepSeek）。

## 六、配置系统（config.ini 重点节）

```ini
[local_llm]    vlm_enable=1  rkllm_model=…  vision_model=…  npu_core_num=3  # vision 编码器 3 核（AUTO 实测慢 3 倍）
[chat]         chat_enable=1  tts_provider=piper|cloud  wake_word=你好 …
[vlm_pipeline] confirm_enable=1  confirm_timeout_ms=12000  confirm_fallback=alarm
               ignore_report=1  confirm_prompt=…
               status_enable=1  status_interval_sec=30  status_min_idle_sec=10  status_prompt=…
               remote_enable=1  remote_token=  remote_voice=0
[mqtt]         topic=home/fall  timeline_topic/cmd_topic/resp_topic/state_topic（{device_id} 占位符）
               subscribe_enable=1  broker_url/username/password…
[event]        device_id=rk3588_home_001（演示客户端 config.json 必须一致）
```
新增配置一律：config.h 结构体默认值 → config.cpp 解析 + saveDefault 输出（老 ini 无新节也能跑）。
