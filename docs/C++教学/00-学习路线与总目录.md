# C++ 教学(以本项目为教材)——学习路线与总目录

> 适用读者:只学过 C,没学过 C++。全程使用本项目的真实代码做教材——
> 你既是项目的开发者(知道每个功能干什么),又是 C++ 的学习者(不知道这些
> 代码为什么这么写)。学完这套文档,你同时获得:C++ 能力 + 对项目每一行的理解。

## 为什么这个项目是绝佳的 C++ 教材

- 它是**真实的工业级板端程序**:多线程、网络、硬件驱动、AI 推理、状态机全都有
- 它的 C++ 用法**务实不炫技**:没有模板元编程,没有继承树,全是 C++11 最实用的部分
- 你**参与过它的开发**:每个模块的功能你都懂,可以把全部注意力放在语言上
- 它有一部**踩坑史**:我们踩过的 segfault、double free、use-after-free、缓冲区语义 bug,每个都是活的教材(第 12 章)

## 每章的统一结构

1. **C 视角**:用你会的 C 概念引出问题("C 里这么做,有什么缺点")
2. **C++ 解法**:新语法的动机和语法
3. **项目实例**:引用真实代码(文件+函数),逐行讲解
4. **思考题**:动手改一行/预测行为
5. **一句话总结**

## 学习方法建议

1. 每章先快速过一遍概念,再精读"项目实例"部分
2. 思考题**先想后试**——在 PC 上写 20 行小代码验证,比读十遍有效
3. 第 12 章的每个 bug 都值得自己重新推导一遍"为什么会崩"
4. 学完一章,回到项目代码把对应模块完整读一遍
