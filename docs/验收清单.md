## 第一幕：家中正常（时间线 + 异网问答）

| 步骤 | 期望现象 | 判据 |
|---|---|---|
| 1. 板端启动，人在画面中静置 | 30s 后出现第一条巡检 | 日志 `[Patrol] 摘要="…" 人数=1` |
| 2. 时间线落库 | events 表出现 timeline 行 | `sqlite3 /AI/events/database/events.db "select event_type,description from events where event_type='timeline'"` |
| 3. 时间线推送 | PC 客户端打印摘要 | mosquitto_sub 或 remote_demo 自动打印 `[时间线]` |
| 4. 无人 10 分钟 | 零 timeline 行、零 VLM 调用 | 日志持续 `[Patrol]` 无新条目；sqlite3 行数不变 |
| 5. 对话期间不巡检 | 巡检顺延 | 对话完成后 ≥10s 才出现下一条 [Patrol] |
| 6. 异网问答 | 回复与画面一致 | remote_demo `c 现在发生了什么` → 应答内容对得上现场 |
| 7. 异网快照 | <1.5s 收到、图正确（含无人空房间） | remote_demo `s` → shot_*.jpg 打开核对 |
| 8. 设备状态 | retained online | remote_demo 启动时收到 `[设备] online`；`p` 返回人数 |

## 第二幕：模拟跌倒（确认链 + 静默报警）

| 步骤 | 期望现象 | 判据 |
|---|---|---|
| 1. 真跌倒（缓慢倒地） | 日志链路完整 | `[AI] 跌倒事件生成` → `[Confirm] 图=… verdict=1 耗时=…` → `[AI] ★真跌倒确认★ urgent 报警已推送` |
| 2. 报警分级 | MQTT 含 severity 字段 | `mosquitto_sub -t home/fall -v` 见 `"severity":"urgent"` + `"vlm_confirm":1` + `"vlm_reply":"…"` |
| 3. **静默** | 板端全程不出声 | 耳听确认（跌倒静默报警设计；老人主动喊"救命"时语音照旧） |
| 4. 证据保全 | 图/录像/DB 完整 | `sqlite3 … "select image_path,video_path,vlm_confirm from events order by id desc limit 1"` |
| 5. 躺沙发/坐姿快速坐下 | 期望 verdict=0 或 2 | 日志 `[Confirm] verdict=0/2`；verdict=0 时收到 `"severity":"cleared"` |
| 6. 蹲下捡物 | 同上 | 同上 |
| 7. 复核超时兜底 | attention 直报 | 断 NPU/加 `confirm_timeout_ms=500` 测试 → `"severity":"attention"` |
| 8. 抢占（语音播报中跌倒） | 播报句间掐断、复核 ≤5s 开始 | 耳听 + 日志顺序：`抢占静默：丢弃待播句` → `[Confirm]` |
| 9. 抢占（语音生成中跌倒） | `rkllm_abort` 生效 | 日志 `生成被复核抢占` → `[Confirm]`；若异常回退注释 cancelRun（一行） |
| 10. 延迟打点 | 候选→urgent 推送 ≤5s（p50/p95） | 日志 `[Confirm] 耗时=` + MQTT 时间戳对比，记录 20 次 |

## 第三幕：故障演练

| 步骤 | 期望现象 | 判据 |
|---|---|---|
| 1. 杀 broker → 重启 | 板端指数退避重连、**重订阅生效** | 日志 `MQTT attempting to connect…`；恢复后 remote_demo 再发命令能收 |
| 2. 断网重启全流程 | 全本地闭环 | 拔网线重启：巡检/复核/对话（VLM+Piper）全部正常 |
| 3. 关 VLM 回退 | 旧行为逐字节 | `[local_llm] vlm_enable=0` 重启：跌倒直报、无 severity/vlm_confirm 字段 |
| 4. 关复核回退 | 同上 | `[vlm_pipeline] confirm_enable=0`：报警照旧无新字段 |
| 5. auth 校验 | 错 token 拒 | `[vlm_pipeline] remote_token=xxx` 后：不带/错 token → `[应答] 失败 code=401`；正确 token 通过 |
| 6. 退出发布 | offline retained | Ctrl+C 板端 → remote_demo 收到 `[设备] offline` |
| 7. 巡检期间 AI 帧率 | 不塌 | 巡检执行时 [SUB] 统计行帧率仍 30fps（记录数字供简历） |
